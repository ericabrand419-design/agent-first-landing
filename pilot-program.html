What gets measured, and why

Five numbers, each tied to a real cost.

Every metric is measured against how your account runs today, before the pilot starts, so the comparison is to your own baseline, not an industry average.

Decision resolution time
How long a call takes when the agent does not have to search for the answer. Shorter calls mean more capacity from the same agents.
Correct-client rule application
How often the agent applies the right client's rule to the right call, not another client's. This is the specific failure mode Agent First is built to prevent.
First-contact accuracy
Whether the customer gets the right answer on the first call, not a callback later to fix it. This is what a QA process is usually trying to catch after the fact.
Supervisor pull-ins
How often an agent has to stop and ask someone else what to do. Fewer pull-ins means supervisors spend less time answering questions a system could answer instead.
New-hire ramp time
How long it takes a new agent to work calls at full speed. Faster ramp means fewer weeks of a new hire's time spent before they are fully productive, and less cost lost every time someone leaves.
