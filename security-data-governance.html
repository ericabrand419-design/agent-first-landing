What the reviewed source shows today

  • Private Deal Room login delegates to the separate Agent First product/auth service.
  • Landing private-access cookie is configured HttpOnly, Secure, SameSite=Lax with a 12-hour Max-Age.
  • Protected Deal Room routes validate the private token and Deal Room permission.
  • Browser local storage holds Deal Room presentation role and visit count, not account credentials.
  • Limited event metadata is written through a serverless logging endpoint.
  • Invite activation tokens currently travel in URL query parameters and require pre-production review/hardening.
  • A legacy Deal Room auth/event path remains in source and should be reconciled or removed.
Evaluation-ready is not production-data ready.
Fictional or appropriately de-identified demos, Test Mode and workflow configuration can proceed today. Proprietary production procedures, customer-specific operating material, sensitive production context or regulated information wait for the Security Readiness Gate.

Compliance posture

Agent First does not claim SOC 2 certification or attestation today. It does not make blanket HIPAA/BAA or PCI claims. Formal assurance and sector-specific compliance follow only when the actual architecture, data and target buyers justify them.
