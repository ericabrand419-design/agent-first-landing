Pricing
RIGHT CLIENT. RIGHT ACTION.

Simple, seat-based pricing.

One rate per agent, per month, plus a one-time implementation fee to build the Profile that holds each client's approved rules. That's the whole model.

Plans

The tier that matches your deployment.

Your tier is assigned by Agent First based on the deployment: scope, seat count, implementation complexity, number of Client Profiles, integration requirements, and support requirements. You don't self-select a tier because it looks cheaper on a chart. We determine which commercial tier applies once we understand what you're actually running.

Starter
$69 / agent / mo
For a single, straightforward deployment: one Client Profile at standard implementation and support scope.
Growth
$49 / agent / mo
Available for qualifying larger deployments with standardized implementation and support requirements. Eligibility is determined by Agent First based on deployment scope.
Enterprise
Custom
For deployments requiring custom integrations with proprietary analytics, QA, workforce-management, CRM, scheduling, or other company-specific systems, plus specialized security, reporting, or implementation requirements. Technical feasibility and pricing are determined after review.

Plans are assigned based on deployment scope. Growth and Enterprise pricing are not self-selected tiers. Assignment is worked out together for each account, based on seat count, number of Client Profiles, implementation complexity, integration requirements, and support requirements.

Rule changes after launch, for rules already covered in your Client Profile, are included in your monthly seat price. Standing up an entirely new line of business or a large new ruleset is scoped separately, as its own implementation.

The implementation fee

$2,500 one-time Profile implementation fee.

This is what funds your Profile implementation: the real policy language for one client, account, location, practice, branch, program, or any other comparable operating ruleset, entered once into a structured rule set every agent can rely on from their very first call. It's a one-time cost per Profile, not a recurring charge, and it's waived entirely for pilot partners.
