How it decides

Not a document to search. A live authorization.

A knowledge base tells an agent where a policy lives. Agent First answers a narrower question: given this client, this customer, and this moment, what should the agent do right now? Every answer resolves to one of a small set of plain outcomes, not a paragraph to interpret.

ALLOW / DO NOT ALLOW
Whether the agent can proceed on their own.
VERIFY
A detail to confirm before deciding anything else.
DISCLOSE
A specific line this client requires the agent to say out loud.
TRANSFER / ESCALATE
When the call, or the decision, belongs with someone else.

Inside one industry, adding a client is genuinely configuration: real rules entered once, running on the same engine already live today. Reaching that same depth in a brand new industry is the direction the architecture is built toward, not a claim already proven.

Questions

A few things people ask first.

Does this replace agents?
No. The agent stays on every call and has the final word every time. Agent First hands them a decision and the exact words to say. It does not talk to the customer.
What does setup look like for a new client?
A client's real rules get entered once into a structured Client Profile. It's a configuration process, not a software build, though the time it takes depends on how many exceptions that client's real rules actually have.
What happens to a client's rules once they're entered?
Each client's Client Profile is its own configuration. One client's rules are never visible in another client's calls, even when the same agent works both.
Are you looking for pilot partners?
Yes. The Starter tier is built for exactly that: a pilot to test Agent First against real rules and real calls before deciding whether to expand further.
How is this different from a script or a knowledge base?
A knowledge base tells an agent where a policy lives. Agent First resolves that policy into one specific answer for this client, this customer, and this moment, instead of leaving the agent to interpret it live.
