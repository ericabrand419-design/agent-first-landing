Pilot Operations Execution Manual

A practical operating manual for taking one qualified customer from scoped observation and workflow discovery through decision mapping, configuration, a measured live pilot, final readout, conversion decision, and clean offboarding.

Commercial baseline

TERM

90-day paid pilot

The pilot is a bounded evaluation, not an open-ended consulting engagement.

PRICE

$69 / agent / month

The customer pays the normal per-agent software rate during the evaluation.

IMPLEMENTATION

$2,500 Profile fee waived

Accepted pilot partners receive the standard Profile implementation fee at no charge, plus a $500 immediate conversion credit if they continue.

Do not launch because a prospect is excited. Launch only when there is a bounded workflow, named sponsor, rule owner, permitted data boundary, measurable baseline, decision date, and a plausible path to continued paid use.

Qualification and acceptance

Strong-fit signals

  • Multi-client or rules-heavy frontline work
  • Agents search, escalate, or guess because context is fragmented
  • Being wrong has a visible quality, cost, compliance, or CX consequence
  • A sponsor can provide source rules and approve configuration
  • A baseline can be measured

Reject / defer signals

  • No sponsor or rule owner
  • Customer wants broad production use before security/data boundaries are cleared
  • Success is defined only as “people like it”
  • The workflow requires a customer-specific fork of the core product
  • The buyer expects custom consulting disguised as a pilot

Required discovery

  • Observe a representative slice of the real workflow before configuration
  • Capture systems, searches, handoffs, workarounds, and decision points
  • Identify where agents lose time, accuracy, or confidence
  • Compare documented work with observed work and rule-owner expectations
  • Confirm what the buyer would need to see to continue after the live pilot

Weekly operating cadence

Customer review

  • Metric snapshot
  • Agent adoption / usability
  • Rule changes requested
  • Unexpected cases
  • Open security/data issues
  • Next-week decisions

Issue severity

  • Critical: security/data boundary, wrong high-risk instruction, outage blocking pilot
  • High: repeated wrong routing/eligibility/required wording
  • Medium: incomplete guidance or confusing workflow
  • Low: cosmetic or convenience issue

Change governance

Client rules do not silently change. Proposed → reviewed → approved → published → superseded/rolled back. The customer owns the underlying policy; Agent First owns the platform/configuration system.

Final readout standard

A pilot is successful only if the evidence answers the decision question—not because the demo looked impressive.

Report

  • Scope and population
  • Baseline and method
  • Observed result
  • Adoption / usage
  • Errors, limitations, confounders
  • Customer qualitative feedback

Decision

  • Continue
  • Expand
  • Revise and retest
  • Stop

Evidence handoff

Raw measurements move to the Evidence Register. Nothing becomes a public claim until support, limitations, and customer permission are reviewed.
