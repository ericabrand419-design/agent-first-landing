Security is part of the Agent First product architecture. The company can continue demos and controlled evaluation with fictional or de-identified material, but proprietary production client information does not enter a live production pilot until the Security Readiness Gate is passed.

PRE-PRODUCTION REQUIREMENT

The Security Readiness Gate

Policy: Prototype/demo work may continue with fictional or appropriately de-identified data. Before a real production pilot receives proprietary procedures, client-specific operating material, sensitive production context, or regulated data, Agent First will complete an architecture/application-security review, remediate critical findings, harden the pilot environment, and document the approved data boundary.

This is not a claim that the current product is insecure. It is the operating discipline required before the company asks a customer to trust Agent First with proprietary production information.

External security engagement scope

Architecture & threat model

Systems, data flows, trust boundaries, assets, threats, dependencies and attack surfaces.

Identity & authorization

Authentication, sessions, reset/MFA path, RBAC, tenant isolation, Agent/Supervisor/Admin boundaries and server-side enforcement.

Data & AI flow

Datastores, APIs, uploads, model/provider calls, retention/training settings, encryption and cross-customer isolation. If a third-party workflow/screen-capture service is used during discovery, its capture scope, storage, retention, access, subprocessors, and deletion behavior are included in this review.

Operational security

Secrets, logging/audit, monitoring, backups/recovery, deletion/export, incident response and administrative actions.

Supply chain

Dependencies, GitHub/deployment permissions, build chain, vulnerability/dependency scanning and update practices.

Verification

Code/security review, targeted penetration testing, OWASP ASVS 5.0 mapping and prioritized remediation report.

Gate criteria before proprietary production data

  • Architecture/data-flow map and threat model completed for the actual pilot architecture.
  • Tenant/company/Client Profile isolation and Agent/Supervisor/Admin authorization enforced server-side and tested against URL/API/storage manipulation.
  • Authentication/session lifecycle and account-recovery path reviewed; MFA/SSO roadmap documented where needed.
  • Database/API object ownership and administrative write paths reviewed.
  • Secrets and infrastructure credentials inventoried and kept out of client code/repository.
  • Encryption in transit and at rest verified across each relevant provider rather than assumed.
  • AI/model-provider data flow, retention/training settings and contractual handling documented.
  • Upload/source-ingestion authorization, validation, storage and deletion reviewed.
  • Authentication, access-control, admin and security events logged appropriately without unnecessary sensitive content.
  • Backup/recovery, retention, deletion/export and incident-response procedures documented.
  • Dependency/supply-chain scanning and remediation process active.
  • Critical/high findings remediated or explicitly accepted with documented rationale and reviewer sign-off.
  • Permitted/prohibited data categories defined in the pilot scope/SOW.

Frameworks used

OWASP Top 10:2025 informs priority risks; Broken Access Control remains A01. OWASP ASVS 5.0 provides a practical application-security verification requirements set. NIST SP 800-218 SSDF provides a secure-development operating framework. These references guide engineering and verification; using them does not itself constitute certification.

Not the plan: rush into SOC 2 simply because enterprise SaaS companies eventually do it. Formal assurance should follow architecture maturity and actual buyer requirements. The immediate job is to make the production-pilot environment defensible and testable.

Product story

Keep the human. Upgrade the agent. Security extends the same principle: Agent First should deliver the right information, for the right client, at the right moment — and only to the right person.
